# burncaps-assets

Static files for [burncaps.app](https://burncaps.app), served through jsDelivr.

- `mediapipe/`: Google MediaPipe models (face detection, selfie segmentation, selfie multiclass), unchanged copies of Google's published files, licensed under the Apache License 2.0 (see `mediapipe/LICENSE`). They run inside the visitor's browser; nothing about the visitor is sent anywhere by them.
- `take/`: the demo video on the Burncaps home page (the presenter is AI-generated) and its poster frame. Copyright Jordan Labs Ltd, all rights reserved.

## Later tags (each an orphan holding only its own files; jsDelivr serves a tag only while it is under 50 MB)
- v6: `sample/coach-sample.part*`, the in-app sample: "How to properly leg press", Colossus Fitness, CC BY 3.0, Wikimedia Commons, re-encoded at 720p; plus showcase loops from The Spruce Eats and Colossus Fitness (CC BY 3.0).
- v7, v8: `showcase/`, the home page loops; sources and credits in each tag's README and on https://burncaps.app/about#credits.
