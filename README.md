# burncaps-assets, tag v6 (showcase and sample only)

jsDelivr serves a tagged GitHub version only while the whole tag is under 50 MB, so v6 is an orphan tag holding only these files (the MediaPipe models and the demo take stay on v2).

## showcase/ (28 Oct 2026)
Short muted loops of real clips that Burncaps cut and captioned, shown on burncaps.app's home page. Every source was published by its own creator under CC BY 3.0 on Wikimedia Commons. Cut, framed and captioned by Burncaps; shown as examples, not an endorsement.
- cooking-dumplings: from "Homemade Dumplings, 3 Ways - Jiaozi, Pancit Molo, Xiaolongbao | It's Elementary - CookWithUs", The Spruce Eats, CC BY 3.0.
- fitness-toes, fitness-feet: from "How to properly leg press", Colossus Fitness, CC BY 3.0.

## sample/coach-sample (28 Oct 2026)
The in-app sample: "How to properly leg press", Colossus Fitness, CC BY 3.0, Wikimedia Commons, re-encoded at 720p. Split into byte parts (each under jsDelivr's file limit) that the page joins back into the one MP4.
